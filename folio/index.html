What a Warden brings to a studio

  • Build machines and pipelines that don't fall over the night before a milestone.
  • Source control that copes with huge binary assets: Git, GitLab, Perforce.
  • Networks, identity, VPN and backups for on-site and remote teammates.
  • Security that keeps unreleased builds where they belong. Leaks are a studio's dragon.
  • Docs and training, so knowledge doesn't live in one person's head.
